1原始数据输入层

CT (Computed Tomography) — 计算机断层扫描
通过X射线环绕人体旋转扫描，经计算机重建得到的人体内部横断面图像。每个像素的值以HU（Hounsfield Unit，亨氏单位）表示，反映组织对X射线的衰减程度。
HU = 1000 × (μ_material - μ_water) / μ_water
HU值范围与肺窗
空气≈-1000 HU，脂肪≈-100 HU，水=0 HU，软组织≈+40 HU，骨≈+1000 HU。肺组织因含气，HU值约-800至-600。本实验使用肺窗：
窗宽 WW = 1400 HU（-1000 至 +400），窗位 WL = -300 HU
LIDC-IDRI数据集
Lung Image Database Consortium and Image Database Resource Initiative。包含1018例胸部CT扫描，每例最多由4位放射科医生独立标注结节。是肺结节研究领域最权威的公开数据集。
数据形状：每例CT为3D体数据，维度约为 [切片数, 512, 512]，每个像素为int16类型的HU值。

2标注解析与共识构建层

XML标注文件
每位放射科医生的标注以XML格式存储，包含结节的轮廓坐标（roi坐标点）、结节特征（恶性程度、钙化、毛刺等）。4位医生的标注分别独立存储。
V(x) — 投票计数函数
对图像中每个像素x，统计有多少位放射科医生将其标记为结节。取值范围为{0, 1, 2, 3, 4}。
V(x) = Σᵢ₌₁⁴ 𝟙[rater_i marks x as nodule]
p(x) — 共识概率（Consensus Probability）
本实验的核心创新概念。不将4位医生的标注融合为0/1硬标签，而是保留为连续概率值，表示"该像素属于结节的医生投票比例"。
p(x) = V(x) / 4 ∈ {0, 0.25, 0.5, 0.75, 1.0}
d(x) — 标注分歧度（Disagreement）
衡量医生之间在像素x处的意见不一致程度。当所有医生意见一致时（p=0或p=1），分歧度为0；当2:2平分时（p=0.5），分歧度最大为1。
d(x) = 4 × p(x) × (1 - p(x)) ∈ [0, 1]
多数投票掩膜（Majority-Vote Mask）
将共识概率二值化得到的硬标签。当至少2位医生（≥半数）标记某像素为结节时，该像素为前景。
M_maj(x) = 𝟙[p(x) ≥ 0.5] = 𝟙[V(x) ≥ 2]
并集掩膜（Union Mask）
只要有任何一位医生标记为结节，该像素即为前景。这是传统方法常用的训练目标，但会显著高估结节边界。
M_union(x) = 𝟙[V(x) ≥ 1]
关键对比：本实验证明，使用共识概率p(x)作为训练目标比使用并集掩膜M_union(x)的Dice系数高出4.0个百分点（0.879 vs 0.838）。这是全文最核心的实验发现。

3结节重定义与Patch裁剪层

连通域（Connected Component）
在二值掩膜中，由相邻（4邻域或8邻域）的前景像素组成的独立区域。每个连通域对应一个候选结节。
等效直径（Equivalent Diameter）
将不规则形状的连通域面积换算成等面积圆的直径，用于统一衡量结节大小。
D_eq = 2 × √(Area / π)，Area为连通域像素数×像素间距²
结节定义标准（本实验的关键数据决策）
仅保留同时满足以下两个条件的连通域作为"有效结节"：
① 在多数投票掩膜M_maj中形成连通域（≥2位医生同意）
② 等效直径 ≥ 3 mm
过滤掉：<3mm的检测级标注（LIDC-IDRI中<3mm仅记录不要求轮廓）和单医生噪声标注。
Patch Bank — 预裁剪结节图块库
以每个有效结节的质心为中心，从CT切片中裁剪出固定大小的正方形区域，预先存储为独立文件。训练时直接加载patch，无需从全图动态裁剪，I/O速度提升约30倍。
数据形状变化：
原始CT切片 [512, 512] int16(HU)
→ 肺窗归一化后 [512, 512] float32[0,1]
→ 共识概率图 [512, 512] float32{0,0.25,0.5,0.75,1.0}
→ 裁剪为Patch [128, 128] float32（单通道CT）
→ 输入网络时复制为3通道 [3, 128, 128]（适配ImageNet预训练权重）

4数据划分与增强层

病例级划分（Patient-Level Split）
按患者（而非按切片或patch）划分训练/验证/测试集，确保同一患者的所有切片只出现在一个子集中。这是医学影像实验的基本要求，防止数据泄露。
子集患者数结节patch数用途
训练集 (train)~70%~8,800模型参数学习
验证集 (val)~15%~2,200超参数选择、早停、消融实验
测试集 (test)~15%~2,209最终性能报告（仅使用一次）
5折交叉验证（5-Fold Cross-Validation）
将训练+验证池划分为5份，轮流用4份训练、1份验证，重复5次。报告5次结果的均值和标准差，用于评估模型的稳定性。本实验结果：0.8675 ± 0.0097。
数据增强（Data Augmentation）
训练时对输入patch施加随机变换， artificially 扩大训练集分布，防止过拟合。本实验使用：随机水平翻转、随机旋转（±15°）、随机亮度/对比度扰动。

ResNet-34编码器
残差网络（Residual Network），34层深度。通过跳跃连接（skip connection）解决深层网络的梯度消失问题。在ImageNet（120万张自然图像）上预训练，迁移到医学影像任务。4个阶段的输出通道数为[64, 64, 128, 256]，空间分辨率逐步降为[1/2, 1/4, 1/8, 1/16]。
U-Net解码器
对称的上采样路径，通过双线性插值将特征图逐步恢复到原始分辨率。每个上采样步骤与编码器对应层的特征进行拼接（concatenation），即"跳跃连接"，保留浅层的空间细节信息。
双分支输出头（Dual Head）
解码器输出的共享特征同时送入两个独立的1×1卷积层：
① 区域头（Region Head）：输出每个像素属于结节区域的概率，是主分割输出。
② 边界头（Boundary Head）：输出每个像素属于结节边界的概率，用于BRBC损失约束区域预测的边缘锐利度。
Logits与Sigmoid
网络原始输出为logits（未归一化的实数，范围(-∞,+∞)）。通过Sigmoid函数映射到(0,1)区间，得到可解释为概率的输出。
σ(z) = 1 / (1 + e^(-z))

Dice损失（Dice Loss）
基于Dice相似系数（衡量两个集合重叠程度）的损失函数。对类别不平衡（前景像素远少于背景）具有天然鲁棒性。本实验中与多数投票硬掩膜M_maj计算。
Dice = 2|A∩B| / (|A|+|B|)，L_dice = 1 - Dice
BCE损失（Binary Cross-Entropy）— 创新使用方式
传统BCE与0/1硬标签计算。本实验的关键创新：BCE与连续共识概率p(x)计算，使网络直接回归医生投票分布，而非被强制拟合一个二值化后的硬标签。这保留了标注分歧中的边界信息。
L_bce = -[p(x)·log(ŷ) + (1-p(x))·log(1-ŷ)]，ŷ为网络预测概率
SITL — 尺度不变实例监督损失（Scale-Invariant Target Loss）
对每个独立的结节连通域（实例）分别计算Dice，然后对所有实例取等权平均。传统Dice在整图上计算，大结节会主导梯度，微小结节被忽略。SITL确保每个结节无论大小都贡献相等的梯度。
L_sitl = (1/N) Σᵢ₌₁ᴺ (1 - Dice_instance_i)，N为batch中实例总数
CSL — 共识软标签损失（Consensus Soft Label Loss）
两个子项的组合：
① 共识加权BCE：医生意见一致的区域（分歧度d低）赋予高权重，分歧区域赋予低权重。权重 w_c = 1 - β·d(x)，β=0.75。
② 分歧低置信惩罚：在医生分歧区域，强制网络预测概率接近0.5（低置信度），而非强行做出0/1判断。
L_csl = mean[w_c·BCE(ŷ, p)] + mean[d(x)·(ŷ-0.5)²]
BRBC — 区域-边界双向一致性损失（Boundary-Region Bidirectional Consistency）
利用区域预测和边界预测的内在几何关系进行互约束：
① r2b（region→boundary）：区域概率图的梯度幅值（边缘强度）应与边界头的预测一致。
② b2r（boundary→region）：边界像素处区域预测应有锐利过渡，非边界处应平滑。
③ 低权重BCE锚定边界头，防止其坍缩。
Lovász-Softmax损失
IoU（交并比）的凸代理（surrogate）损失函数，直接优化与评估指标一致的目标。与Dice互补，提升小目标的分割质量。
总损失公式：
L = 1.0·L_dice + 1.0·L_bce + 1.0·L_sitl + 1.0·L_csl + 0.5·L_brbc + 0.3·L_lovasz

7优化与训练循环层

AdamW优化器
Adam优化器的变体，将权重衰减（weight decay）从梯度更新中解耦，实现更规范的L2正则化。本实验使用编码器学习率1e-4，解码器学习率1e-3（解码器从头训练需更大学习率）。
余弦退火学习率调度（Cosine Annealing）
学习率按余弦函数从初始值平滑衰减到最小值，有助于模型在训练后期精细收敛。前3个epoch为warmup（线性升温），防止初始大学习率破坏预训练权重。
早停（Early Stopping）
监控验证集上的Dice指标，若连续12个epoch没有提升，则停止训练，取验证集性能最好的模型。防止过拟合。本实验主模型在第40个epoch早停（最大60 epoch）。
混合精度训练（AMP, Automatic Mixed Precision）
使用bf16（Brain Floating Point 16位）格式存储部分张量，减少显存占用和计算量，同时保持与fp32相近的数值稳定性。梯度裁剪（grad_clip_norm=5.0）防止Lovász/BRBC损失的梯度尖峰导致训练不稳定。

8评估与输出层

Dice系数（Dice Similarity Coefficient, DSC）
医学影像分割最常用的评估指标，衡量预测掩膜与真实掩膜的重叠程度。取值范围[0,1]，1为完美重合。
Dice = 2·TP / (2·TP + FP + FN)，TP=真阳性，FP=假阳性，FN=假阴性
IoU（Intersection over Union，交并比）
预测与真实的交集面积除以并集面积。与Dice单调相关但对小误差更敏感。
IoU = TP / (TP + FP + FN) = Dice / (2 - Dice)
HD95（95% Hausdorff Distance，95%豪斯多夫距离）
衡量两个点集之间的最大不匹配距离。取95百分位数以排除离群点的极端影响。单位为mm，越小表示边界越精准。
ASSD（Average Symmetric Surface Distance，平均对称表面距离）
预测边界与真实边界上所有对应点对距离的平均值。比HD95更全面地反映整体边界精度。单位为mm。
结节大小分层评估
按等效直径将结节分为4层，分别报告Dice：
① 微小结节（micro）：3–5 mm — 临床最关注，最难分割
② 小结节（small）：5–10 mm
③ 中等结节（medium）：10–30 mm
④ 大结节（large）：>30 mm
